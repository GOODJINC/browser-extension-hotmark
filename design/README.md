# Design assets

This directory contains the source artwork and publishing assets for Hotmark.

## Structure

- `icon-master.png`: original high-resolution icon artwork
- `store-assets/`: submission-ready Chrome Web Store images
- `../docs/images/`: optimized WebP previews used by the repository README files

The deleted raw browser screenshots are not required for publishing. Keep the submission-ready PNG files unchanged so their dimensions remain valid for the Chrome Web Store.
